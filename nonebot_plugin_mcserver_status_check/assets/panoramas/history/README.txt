Minecraft Java Edition historical title panorama assets.
sets/<version>/ contains the six original square cubemap faces without title text or UI.
equirectangular/<version>.jpg contains a compact 1536x768 2:1 panorama derived from those faces.
manifest.json maps Java release versions to deduplicated face sets and generated panoramas.
The face sources remain in the repository but are excluded from the wheel and source distribution.
Sources: Mojang launcher metadata and official client asset objects.
